# ADR 0014: pinned golden gates, independent reviews and explicit trace export

Status: implemented for B13 review. Date: 25 October 2026.

Preserve BRD business acceptance, the existing 17-case catalog and its five-failure denominator. Execute versioned recorded cases against actual harness/graph/storage where specified; label two component cases honestly. Grade artifacts and durable decisions independently, with mutation/privacy negatives. Keep expected fixtures separate from observed outputs and a proposed, non-overwritable baseline. Version/hash mismatches and critical regressions block deterministic CI; human/semantic unknowns block release rather than becoming fixture scores.

Do not treat a URL/hash/quote as support or generate owner opinions. Add owner-protected review packets and explicit server-granted human review/rating endpoints bound to exact immutable report/claim/source versions. Append receipts in existing immutable evaluation rows. Fixture judgments and self-labelled JSON never count toward human gates. Default role grants are empty. The fixed usefulness cohort is five distinct predeclared saved reports, with actual useful/not-useful decisions, preserving the original four-of-five target.

Keep provider/model selection neutral and quality-first. Model fault fixtures remain synthetic rule-output projections. No real model/semantic quality or live market success follows from deterministic mechanics. Record measured local replay latency and accounting, and distinguish zero provider activity from unknown billing or token estimation.

Use a sanitized trace projection and real pinned LangSmith SDK with network-free tests. Remote export requires a separate explicit approved, capped command to an existing project; no automatic worker telemetry, raw prompts/sources/owners/credentials or cloud provisioning. CI receives no paid provider/trace credentials. The app's existing automatic-tracing prohibition remains intact.

A golden job is a versioned optional plan, allowed only by the isolated test worker/CLI gates; production rejects it. No database migration or graph payload version change is needed. Hash-pinned inputs/baselines retain bytes across checkout. The terminal-news fixture exposed a real reporting ambiguity: failed search now records a limitation instead of masquerading as an empty result. Retain already completed lanes and normal bounded retry behavior.

Consequences: reproducible regression evidence and reviewable gaps, with more explicit approval/identity setup for human scores and trace export. Hosted LangSmith compatibility, actual owner judgments, independent semantic support, real-source adequacy and the paid provider-neutral benchmark remain unmeasured until separately authorized/executed. Stop for review before B14 or any further stage.
