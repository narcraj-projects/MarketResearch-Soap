# ADR 0003 Evidence observations and deterministic evaluation

Status: proposed for review. Date: 25 October 2026.

Context: FR-03–07 require source support, comparable data, distinctions between facts/interpretations/hypotheses and useful recommendations. BRD section 12 separates source traceability from completeness; section 11 forbids unsupported skincare assertions.

Decision: retain immutable dated source/price observations and claim-to-excerpt links. Use Decimal for same-SKU pack normalization; missing data stays unavailable/null. Preserve conflicting observations. Type marketing claims separately. Report every required BRD section/field even where prototype labels are shorter. Keep three-to-five opportunity target; insufficient supported ideas are flagged as unmet expectation, never invented.

Version deterministic DEMO tool/model fixtures. Source coverage denominator contains every material factual assertion, including unsupported ones. Zero assertions yields unavailable coverage. Evaluate adequacy separately; owner assesses five actual reports for A04. Predeclare D04/D05/D06/D10/D12 as the A05 failure cohort and publish the entire suite as well.

Alternatives: mutable latest-only data hides conflicts/history; URL-count scoring does not establish support; model-only judging cannot replace owner ratings or deterministic arithmetic.

Consequences: storage/provenance is larger but auditable. Human evidence/usefulness checks remain necessary. Strict security/math/approval/recovery tests can block release even if four of five failure cases pass.

Verification planned: D07–D12/D15, T02–T07, H01; all unexecuted.
